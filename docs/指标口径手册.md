## 0. 使用说明与全局口径

课程样例中的 `sim-discharge-v1` 按出院日期统计，以源住院日和源住院总费用分别除以出院人次。`sim-charge-v1` 计算样例药品及耗材各自的收费额占已分类收费总额的比例，医疗收入口径仍待确认。床位使用率、DRG 入组率和 CMI 保留空值并标注缺失原因。 回刷可用 `metrics` 显式指定已发布主题的新增指标编码。

### 0.1 可计算性分级

| 级别 | 含义 | 处理 |
|---|---|---|
| A 可计算 | 字段与口径均具备，可按本手册直接计算 | 可产出指标值；仍需通过质量门禁与对账 |
| B 部分可计算 | 字段存在，但费别/号别/期间归属/费用范围等口径待确认，或只能近似 | 可产出“候选值”，必须标注口径版本与待确认项；不得直接对外宣称正式口径 |
| C 不可计算 | 缺必要数据源、字段、分组器或权重 | **必须输出 NULL 并记日志**；不得用替代字段、0、样例或手工数冒充 |
| D 待口径（保留） | 定义本身尚未形成可执行公式 | 不产出数值；仅保留指标目录位置 |

> 本手册实际使用 A/B/C 三级；“D 待口径”保留给后续新增指标。A 不代表已验收，B 不代表可对外发布。

### 0.2 编码规则

- 格式：`MOPS-<主题>-<两位序号>`，主题码为 `OUT/INP/INC/DRUG/CONS/DIS/EFF/SRV`。
- 编码一经发布**不复用、不改义**；口径变更时保留原编码并升口径版本（如 `v1 → v2`），旧结果可追溯。
- 新增指标分配新序号；废弃指标标记 `DEPRECATED`，不把序号转给其他指标。
- 结果表唯一键：`指标编码 + 维度值 + 粒度 + 统计日期（口径版本另存元数据，不改变本期唯一键）`。

### 0.3 通用计算约定

1. **统计期含首尾**；日期格式 `YYYY-MM-DD`，不接受空白、简写或日期时间混写。
2. **门诊人次**按 `visit_id` 去重计数，不是患者数、不是收费笔数；空 `visit_id`、非法日期、同 ID 冲突组按质量规则隔离。
3. **出院人次**按 `discharge_date` 归属统计期；无出院日期视为在院，不计入出院人次并记日志。
4. **收入**按 `fee_date` 归属；财务 Excel 按 `stat_date` 归属；两者口径不同，不能直接互相替代。
5. **比率**统一 `分子/分母×100%`，保留 2 位小数；**分母为 0 时输出 NULL**，不输出 0% 或 100%。
6. **金额**单位元，保留 2 位小数；不做汇率换算；退费按负值或冲销规则处理，具体规则待业务确认。
7. **天数**保留 2 位小数；住院日、床日的起止日规则待业务确认。
8. **未映射编码**（科室/费别/号别/病种）保留 `UNMAPPED` 桶并告警；**不猜测映射、不静默合并异名**。若未映射比例过高导致指标失真，输出 NULL。
9. **小样本**：不输出患者级记录；聚合结果按角色数据范围过滤。是否需要最小单元格抑制（如人次 <5 不展示）待业务确认，本手册不擅自设定。
10. **可比性**：同比/环比必须同口径、同维度、同期间类型且完整覆盖（自然月不强求相同天数）；缺上期/上年同期输出 NULL，不用其他期间替代。

### 0.4 NULL 与 0 的区别

- **0 是真实测量结果**：统计期内确实没有有效记录，且源数据完整、质量门禁通过。
- **NULL 是无法计算**：源缺失、文件损坏、必需字段缺失、分母为 0、口径未确认、质量门禁失败。
- NULL 必须写运行日志：指标编码、统计期、维度、原因码、批次、口径版本。**禁止把 NULL 写成 0，也禁止把 0 写成 NULL。**

### 0.6 隐私与输出边界

- `patient_name`、`id_card`、`phone`、`patient_id` 属于敏感字段，**不得出现在 API、日志、导出、图表、tooltip 或本文档示例中**。
- 指标输出只保留聚合维度（日期、科室、号别、费别、病种、DRG 组等）与计数/金额/比率。
- EMR 的 `diagnosis`/`result_text` 不直接输出原文；只输出编码/分类统计。
- 角色数据范围在查询层强制追加，不依赖前端隐藏。

### 0.7 口径变更管理

1. 任何公式、分子分母、排除规则、期间归属变更，必须先提出变更单，经业务方/协调者评审后生效。
2. 当前ADS结果仍用指标编码+规范化维度名称和值组合+粒度+统计日期四项唯一键；口径版本另存元数据。改版替换当前结果前，旧结果先写独立版本归档；归档机制未实现前不得发布覆盖旧口径的回刷。
3. DRG/DIP、CMI、消耗指数在业务方确认分组器与权重版本前**冻结**，不进入生产计算。
4. 本手册当前为 v0.1；评审意见将形成 v0.2，不以“文档已写”代替“口径已批准”。

## 2. 门诊主题（5 项）

### MOPS-OUT-01 门诊人次

- **定义**：统计期内通过质量门禁的门诊就诊记录的唯一 `visit_id` 数。
- **公式**：`COUNT(DISTINCT visit_id) WHERE visit_date BETWEEN start_date AND end_date AND 记录通过质量门禁`
- **维度**：日期、科室 `dept_code`、号别 `visit_type`、院区（待补）。
- **粒度**：日 / 月 / 季 / 年；科室×日；全院×日。
- **来源表**：目标 `ods_his_outpatient_visit`；当前本地 `data/mock_his/his_outpatient.csv`。
- **输入字段**：`visit_id`、`visit_date`、`dept_code`、`visit_type`。
- **过滤/排除**：字段先 trim；空 `visit_id`、非严格 `YYYY-MM-DD`/非法日历日期、同 ID 任意字段冲突组剔除；不按金额过滤；不按患者去重；空科室在首轮合同归 `__UNKNOWN__`，全量需科室字典，不猜名称、不合并异名。
- **当前可计算性**：**A 可计算**。2025-04-01—06-30 样例已独立复算：9000 人次、10 个科室；KPI=日趋势和=科室排行和。该证据只覆盖该 3 个月样例。
- **NULL 原因**：源文件缺失/损坏、必需字段缺失、质量门禁失败 → NULL 并记日志；统计期真实无有效记录 → 0。未知科室不是 NULL，进入 `__UNKNOWN__`/`UNMAPPED` 桶并告警。
- **口径状态/待确认**：课程候选定义：门诊人次 = 唯一 `visit_id` 数，不是唯一患者数，不依赖收费金额。待确认：退号/作废/重复就诊是否计入、跨院区是否合并、复诊是否按人次计。
- **证据/备注**：`contract-v1.md` 明确 `accepted_visits` 与守恒关系；独立审查记录 9000/9000/9000。

### MOPS-OUT-02 门诊人次环比增长率

- **定义**：本期门诊人次相对上一可比期的变化率。
- **公式**：`(本期门诊人次 - 上期门诊人次) / 上期门诊人次 × 100%`；上期=0 → NULL。
- **维度**：全院、科室、号别。
- **粒度**：月环比、周环比；科室×月。
- **来源表**：由 `MOPS-OUT-01` 或 `dws_dept_daily` 派生。
- **输入字段**：`visit_id`、`visit_date`、`dept_code`、`visit_type`。
- **过滤/排除**：本期与上期使用同一质量规则、同一维度、同期间类型且完整覆盖；自然月不强求相同天数；上期不完整（如缺月/缺周）不计算。
- **当前可计算性**：**A 可计算**（字段与口径具备；2025-04—06 完整月份可算 2 个环比；未单独做独立复算）。
- **NULL 原因**：上期数据缺失、上期为 0、期间不完整、口径版本不一致 → NULL。
- **口径状态/待确认**：不做季节性调整、不补零；是否按自然月还是 4 周月待业务确认；节假日是否调整不擅自加入。
- **证据/备注**：环比是派生指标，不重复存储源数据。

### MOPS-OUT-03 门诊人次同比增长率

- **定义**：本期门诊人次相对上年同期的变化率。
- **公式**：`(本期门诊人次 - 上年同期门诊人次) / 上年同期门诊人次 × 100%`；上年同期=0 → NULL。
- **维度**：全院、科室。
- **粒度**：月同比、季同比、年同比。
- **来源表**：由 `MOPS-OUT-01` 派生，需覆盖上年同期。
- **输入字段**：`visit_id`、`visit_date`、`dept_code`。
- **过滤/排除**：同期按日历对齐；闰年 2 月、周同比的 52/53 周问题待确认；不拿环比替代同比。
- **当前可计算性**：**C 不可计算**。现有样例仅 2025-04-01—06-30，无 2024 年同期；即使下一波生成 12 个月，若未覆盖上年同期仍不可算。
- **NULL 原因**：上年同期缺失、上年同期为 0、期间不可比、口径版本不同 → NULL。
- **口径状态/待确认**：课程候选定义；同期选择规则（日历同期/52 周）待确认。
- **证据/备注**：**不得用 12 个月数据冒充同比可用**；同比至少需要两个年度同期。

### MOPS-OUT-04 门诊次均费用

- **定义**：统计期内门诊医疗收入与门诊人次之比。
- **公式**：`SUM(门诊医疗收入) / COUNT(DISTINCT visit_id)`；分子候选一为收费明细 `SUM(amount)`（限定门诊），候选二为门诊表 `SUM(fee_amount)`。
- **维度**：科室、号别、日期。
- **粒度**：月；科室×月；全院×月。
- **来源表**：`ods_his_charge_detail` + `ods_his_outpatient_visit`；当前 `his_charge.csv` + `his_outpatient.csv`。
- **输入字段**：`visit_id`、`visit_type`、`fee_date`、`dept_code`、`amount`、`fee_amount`。
- **过滤/排除**：分子分母必须同期间、同科室、同就诊范围；退费按冲销规则；不把挂号费、药品、耗材等不同范围混用。
- **当前可计算性**：**B 部分可计算**。字段存在，但 `fee_amount` 是挂号费还是就诊总费用未确认；收费明细与门诊表的关联覆盖率未核。
- **NULL 原因**：分母为 0、收入口径未确认、关联失败率过高、退费规则未确认 → NULL。
- **口径状态/待确认**：医疗收入范围（是否含挂号/药品/耗材/检查/治疗）、是否含医保统筹与自费、是否含退费、按发生还是结算时点。**未确认前只能作为候选值，不得对外发布。**
- **证据/备注**：现有门诊切片未计算次均费用。

### MOPS-OUT-05 门诊号别结构占比

- **定义**：各号别门诊人次占同期门诊总人次的比例。
- **公式**：`COUNT(DISTINCT visit_id WHERE visit_type = 某号别) / COUNT(DISTINCT visit_id) × 100%`
- **维度**：号别 `visit_type`、科室、日期。
- **粒度**：月；科室×月。
- **来源表**：`ods_his_outpatient_visit`；当前 `his_outpatient.csv`。
- **输入字段**：`visit_id`、`visit_type`、`visit_date`、`dept_code`。
- **过滤/排除**：空号别/未映射号别进入 `UNMAPPED` 桶并告警；不猜测“普通/专家/急诊”等映射；结构占比之和应为 100%（含 UNMAPPED）。
- **当前可计算性**：**B 部分可计算**。字段存在，但 `visit_type` 取值域与字典未核。
- **NULL 原因**：`visit_type` 整列缺失、空值/未映射比例高到无法形成有效结构、口径未确认 → NULL。
- **口径状态/待确认**：号别字典（普通/专家/急诊/专病/特需等）与合并规则待业务确认。
- **证据/备注**：不将号别结构用于推断患者身份或病情。

## 3. 住院主题（6 项）

### MOPS-INP-01 出院人次

- **定义**：统计期内办理出院的唯一住院 `visit_id` 数。
- **公式**：`COUNT(DISTINCT visit_id) WHERE discharge_date BETWEEN start_date AND end_date AND discharge_date >= admit_date`
- **维度**：科室、出院日期、病种、医保类型（待补）。
- **粒度**：日 / 月；科室×月。
- **来源表**：`ods_his_inpatient_visit`；当前 `his_inpatient.csv`。
- **输入字段**：`visit_id`、`dept_code`、`admit_date`、`discharge_date`、`stay_days`。
- **过滤/排除**：无 `discharge_date` 视为在院，不计入并记日志；出院日期早于入院日期按质量规则隔离；不按费用过滤。
- **当前可计算性**：**B 部分可计算**。字段具备；样例未独立复算，出院状态/转科/日间手术口径未确认。
- **NULL 原因**：源缺失、`discharge_date` 整列缺失、日期非法比例过高、质量门禁失败 → NULL；真实无出院 → 0。
- **口径状态/待确认**：按出院日期归属；死亡出院、转院、转科、日间手术、自动出院是否纳入待确认。
- **证据/备注**：不能用入院日期替代出院日期。

### MOPS-INP-02 平均住院日

- **定义**：统计期内出院患者的总住院日与出院人次之比。
- **公式**：`SUM(stay_days) / COUNT(DISTINCT visit_id 出院)`；或 `AVG(stay_days)`（分母非空时等价）。
- **维度**：科室、病种、日期。
- **粒度**：月；科室×月；全院×月。
- **来源表**：`ods_his_inpatient_visit`；当前 `his_inpatient.csv`。
- **输入字段**：`visit_id`、`stay_days`、`admit_date`、`discharge_date`、`dept_code`。
- **过滤/排除**：`stay_days` 缺失/负值/与日期差不一致时隔离并告警；不纳入在院患者；不把门诊观察计入。
- **当前可计算性**：**B 部分可计算**。字段具备；`stay_days` 与 `discharge_date - admit_date` 是否 +1 未确认。
- **NULL 原因**：分母为 0、`stay_days` 缺失/非法比例过高、日期不一致未解决 → NULL。
- **口径状态/待确认**：住院日 = 出院日-入院日 还是 +1；入院/出院当天是否都计；日间手术、转科、死亡、转院是否纳入。**专业定义待核实权威统计制度/业务口径。**
- **证据/备注**：不得用床位使用率反推平均住院日。

### MOPS-INP-03 实际占用床日

- **定义**：统计期内住院患者实际占用床位的天数总和。
- **公式**：按日展开住院区间后 `SUM(每日在院人数)`；不能用 `SUM(stay_days)` 全额归到出院日。
- **维度**：科室、日期、院区（待补）。
- **粒度**：日 / 月；科室×日。
- **来源表**：`ods_his_inpatient_visit`；当前 `his_inpatient.csv`。
- **输入字段**：`visit_id`、`dept_code`、`admit_date`、`discharge_date`、`stay_days`。
- **过滤/排除**：跨期住院按日切分；转科按转科日期切分（若字段具备）；缺日期无法切分时不估算。
- **当前可计算性**：**B 部分可计算**。有入院/出院日期，可做日切分；跨科转科、请假离院、日间手术口径未确认。
- **NULL 原因**：缺入院/出院日期、日期非法、无法确定科室归属、跨期切分规则未确认 → 该日/该科室 NULL。
- **口径状态/待确认**：床日是否含入院当天/出院当天、跨科归属、停床/加床、请假离院是否计。**专业定义待核实。**
- **证据/备注**：床日与出院人次是不同的分母，不能混用。

### MOPS-INP-04 床位使用率

- **定义**：统计期内实际占用床日占实际开放床日的比例。
- **公式**：`实际占用总床日 / SUM(逐日实际开放床位数) × 100%`
- **维度**：科室、院区、日期。
- **粒度**：日 / 月；科室×月。
- **来源表**：`ods_his_inpatient_visit`（占用床日）+ 床位容量源（缺失）。
- **输入字段**：`admit_date`、`discharge_date`、`dept_code`；**缺** `open_beds`、`campus`、`bed_status`。
- **过滤/排除**：分母必须是实际开放床位，不是床号数量；停用床、加床、院区归属需明确；不使用推定床位数。
- **当前可计算性**：**C 不可计算**。样例只有 `bed_no`（床位编号），没有开放床位数/床位容量台账。
- **NULL 原因**：缺开放床位数/院区/床位状态、分母不可得、口径未确认 → NULL。
- **口径状态/待确认**：开放床位定义、按日还是按月平均、停床/加床、院区合并、分母是否扣节假日。**待补数据 + 待业务口径评审；不得用 `COUNT(DISTINCT bed_no)` 冒充容量。**
- **证据/备注**：`bed_no` 是编号，不是容量；即使编号数恰好等于床位数也不能证明开放床位。

### MOPS-INP-05 床位周转次数

- **定义**：统计期内出院人次与平均开放床位数之比。
- **公式**：`出院人次 / 平均开放床位数`
- **维度**：科室、院区、日期。
- **粒度**：月 / 季 / 年；科室×月。
- **来源表**：`ods_his_inpatient_visit` + 床位容量源（缺失）。
- **输入字段**：`visit_id`、`discharge_date`、`dept_code`；**缺** `open_beds`。
- **过滤/排除**：平均开放床位按日/按月口径待确认；不使用床号计数。
- **当前可计算性**：**C 不可计算**（缺开放床位）。
- **NULL 原因**：缺分母、分母为 0、口径未确认 → NULL。
- **口径状态/待确认**：平均开放床位计算法（每日/每月）、院区与科室归属。
- **证据/备注**：与床位使用率共享同一缺失分母，不能互相替代。

### MOPS-INP-06 住院次均费用

- **定义**：统计期内出院患者住院医疗收入与出院人次之比。
- **公式**：`SUM(住院医疗收入) / COUNT(DISTINCT visit_id 出院)`；分子候选为住院表 `total_fee` 或收费明细 `SUM(amount)`（限定住院）。
- **维度**：科室、病种、日期。
- **粒度**：月；科室×月。
- **来源表**：`ods_his_inpatient_visit` + `ods_his_charge_detail`；当前 `his_inpatient.csv` + `his_charge.csv`。
- **输入字段**：`visit_id`、`total_fee`、`discharge_date`、`dept_code`、`amount`、`visit_type`。
- **过滤/排除**：分子分母同期间、同科室、同出院口径；退费冲销；未结算费用是否计入待确认。
- **当前可计算性**：**B 部分可计算**。`total_fee` 字段具备；费用范围、结算状态、与收费明细对账未核。
- **NULL 原因**：分母为 0、费用字段缺失、对账失败、口径未确认 → NULL。
- **口径状态/待确认**：是否含医保自付/自费、是否含出院带药、是否含未结算、按发生还是结算。
- **证据/备注**：不得用 `drug_fee + consumable_fee` 代替 `total_fee`，除非差额口径已确认。

## 4. 收入主题（5 项）

### MOPS-INC-01 医疗收入总额

- **定义**：统计期内有效收费明细确认的医疗收入合计。
- **公式**：`SUM(amount) WHERE fee_date BETWEEN start_date AND end_date AND 收费记录通过质量门禁`；退费按负值或冲销规则处理。
- **维度**：日期、科室、费别、门诊/住院、院区（待补）。
- **粒度**：日 / 月 / 季 / 年；科室×日。
- **来源表**：`ods_his_charge_detail`；当前 `data/mock_his/his_charge.csv`。
- **输入字段**：`charge_id`、`visit_id`、`visit_type`、`dept_code`、`fee_date`、`fee_type_code`、`fee_type_name`、`amount`。
- **过滤/排除**：`charge_id` 重复按质量规则去重；金额不可解析/负值异常隔离；退费不静默丢弃；科室/费别未映射保留 `UNMAPPED` 并告警。
- **当前可计算性**：**B 部分可计算**。字段具备；收入确认时点、退费、含税、结算状态未确认。
- **NULL 原因**：源缺失、金额不可解析比例过高、质量门禁失败、口径未确认 → NULL；真实无收费 → 0。
- **口径状态/待确认**：按发生制还是收付实现制；是否含税；退费冲销；是否含医保统筹/自费/财政补助；是否含未结算。**未确认前不得对外宣称“准确收入”。**
- **证据/备注**：与财务 Excel 的差异见 `MOPS-INC-05`，不能直接互相替代。

### MOPS-INC-02 医疗收入环比增长率

- **定义**：本期医疗收入相对上一可比期的变化率。
- **公式**：`(本期收入 - 上期收入) / 上期收入 × 100%`；上期=0 → NULL。
- **维度**：全院、科室、费别、门诊/住院。
- **粒度**：月环比、周环比；科室×月。
- **来源表**：由 `MOPS-INC-01` 派生。
- **输入字段**：`fee_date`、`dept_code`、`amount`、`fee_type_code`、`visit_type`。
- **过滤/排除**：同口径、同期间类型且完整覆盖；自然月不强求相同天数、同维度；上期不完整不计算。
- **当前可计算性**：**B 部分可计算**（分子口径本身为 B）。
- **NULL 原因**：上期缺失/为 0、期间不完整、口径版本不同 → NULL。
- **口径状态/待确认**：自然月/4 周月、节假日调整、退费跨期处理。
- **证据/备注**：不把环比当同比。

### MOPS-INC-03 医疗收入同比增长率

- **定义**：本期医疗收入相对上年同期的变化率。
- **公式**：`(本期收入 - 上年同期收入) / 上年同期收入 × 100%`；上年同期=0 → NULL。
- **维度**：全院、科室。
- **粒度**：月/季/年同比。
- **来源表**：由 `MOPS-INC-01` 派生，需覆盖上年同期。
- **输入字段**：`fee_date`、`dept_code`、`amount`。
- **过滤/排除**：日历同期对齐；不拿环比替代；不补零。
- **当前可计算性**：**C 不可计算**（现有样例仅 3 个月，无上年同期）。
- **NULL 原因**：上年同期缺失/为 0、期间不可比、口径不同 → NULL。
- **口径状态/待确认**：同期规则、价格调整/政策变化是否需可比性说明。
- **证据/备注**：12 个月数据不一定支持同比，除非覆盖上年同期。

### MOPS-INC-04 收入结构占比（费别）

- **定义**：各费别收入占同期医疗收入的比例。
- **公式**：`SUM(amount WHERE fee_type = 某费别) / SUM(amount) × 100%`
- **维度**：费别 `fee_type_code/name`、科室、日期、门诊/住院。
- **粒度**：月；科室×月。
- **来源表**：`ods_his_charge_detail`；当前 `his_charge.csv`。
- **输入字段**：`fee_type_code`、`fee_type_name`、`amount`、`fee_date`、`dept_code`、`visit_type`。
- **过滤/排除**：费别字典映射；未映射保留 `UNMAPPED` 桶；结构占比之和应为 100%（含 UNMAPPED）；不猜测费别名称。
- **当前可计算性**：**B 部分可计算**。费别字段存在，但字典与层级未核。
- **NULL 原因**：费别整列缺失、未映射比例过高、口径未确认 → NULL。
- **口径状态/待确认**：费别分类（挂号/检查/检验/治疗/手术/药品/耗材/床位/护理/其他）、层级与合并规则。
- **证据/备注**：药占比、耗占比依赖同一费别字典，必须先统一字典。

### MOPS-INC-05 财务-收费对账差异

- **定义**：财务 Excel 报表收入与 HIS 收费明细汇总收入之间的差异。
- **公式**：`差异金额 = 财务收入 - SUM(收费金额)`，单位元；按 `stat_date`/`fee_date` 与科室对齐。差异率仅可作未注册的展示派生，不复用本指标编码或写成第二种单位。
- **维度**：日期、科室、收入类别（总/药品/耗材）。
- **粒度**：日 / 月；科室×月。
- **来源表**：`ods_finance_excel` + `ods_his_charge_detail`；当前 `finance_excel.csv` + `his_charge.csv`。
- **输入字段**：`stat_date`、`dept_code`、`revenue`、`drug_revenue`、`consumable_revenue`；`fee_date`、`dept_code`、`amount`、`fee_type_code`。
- **过滤/排除**：科室代码先统一映射；期间口径对齐；差异只作质量提示，不能直接判定哪一方错误。
- **当前可计算性**：**B 部分可计算**。两源字段具备；财务口径、期间、含税、医保结算范围未确认；未做真实对账复算。
- **NULL 原因**：任一源缺失、科室映射不一致、期间不可比、口径未确认 → NULL。
- **口径状态/待确认**：财务收入是否含财政补助/医保回款、是否含税、按开单还是结算、退费处理。**不得宣称“对账误差=0”**，除非有真实复算记录。
- **证据/备注**：课程节点要求“抽样 10 项与手工 SQL 复算误差=0”，当前 **NOT RUN**。

## 5. 药品主题（4 项）

### MOPS-DRUG-01 药品收入

- **定义**：统计期内费别属于药品类的收费金额合计。
- **公式**：`SUM(amount) WHERE fee_type IN 药品类 AND fee_date BETWEEN start AND end`
- **维度**：日期、科室、药品类别、门诊/住院。
- **粒度**：日/月；科室×月。
- **来源表**：`ods_his_charge_detail` + 费别字典；当前 `his_charge.csv`。
- **输入字段**：`fee_type_code`、`fee_type_name`、`amount`、`fee_date`、`dept_code`、`visit_type`。
- **过滤/排除**：药品类由费别字典确定；中药饮片、院内制剂、出院带药是否纳入待确认；未映射不猜。
- **当前可计算性**：**B 部分可计算**。字段存在，药品费别字典未核。
- **NULL 原因**：药品费别无法识别、字典缺失、金额不可解析 → NULL；真实无药品收入 → 0。
- **口径状态/待确认**：药品范围（西药/中成药/中药饮片/院内制剂）、零售价 vs 进价、是否含税。
- **证据/备注**：药品收入不等于药品成本，不能用于成本控制结论。

### MOPS-DRUG-02 药占比

- **定义**：药品收入占同期医疗收入的比例。
- **公式**：`药品收入 / 医疗收入 × 100%`
- **维度**：科室、日期、门诊/住院。
- **粒度**：月；科室×月。
- **来源表**：`MOPS-DRUG-01` / `MOPS-INC-01`，同源于 `ods_his_charge_detail` + 费别字典。
- **输入字段**：`fee_type_code`、`amount`、`fee_date`、`dept_code`、`visit_type`。
- **过滤/排除**：分子分母同期间、同范围、同费别字典版本；分母为 0 → NULL。
- **当前可计算性**：**B 部分可计算**（依赖药品费别与收入口径）。
- **NULL 原因**：药品分类缺失、分母为 0、口径未确认、字典版本不一致 → NULL。
- **口径状态/待确认**：是否含中药饮片、是否含出院带药、按收入还是支出、是否剔除疫苗/特殊药品。
- **证据/备注**：课程常把药占比作为运营指标，但**具体口径需业务确认**；不宣称是官方考核口径。

### MOPS-DRUG-03 住院药品费用占比

- **定义**：住院患者药品费用占住院总费用的比例。
- **公式**：`SUM(drug_fee) / SUM(total_fee) × 100%`，限定出院患者与统计期。
- **维度**：科室、病种、日期。
- **粒度**：月；科室×月。
- **来源表**：`ods_his_inpatient_visit`；当前 `his_inpatient.csv`。
- **输入字段**：`visit_id`、`drug_fee`、`total_fee`、`discharge_date`、`dept_code`、`disease_code`。
- **过滤/排除**：`drug_fee > total_fee` 等异常隔离；出院带药是否计入待确认；分母为 0 → NULL。
- **当前可计算性**：**B 部分可计算**。字段具备；费用范围与结算状态未核。
- **NULL 原因**：费用字段缺失/异常、分母为 0、口径未确认 → NULL。
- **口径状态/待确认**：住院费用范围、出院带药、退费、医保结算。
- **证据/备注**：与收费明细口径的药品收入可能不一致，需对账而非直接混用。

### MOPS-DRUG-04 抗菌药物使用强度

- **定义**：按2025药事质控候选版本，统计期住院抗菌药物累计DDD除以同期实际占用总床日并乘100；采用其它版本需另行修订。
- **公式**：`SUM(抗菌药物消耗量 / 该药DDD值) / 同期住院实际占用总床日 × 100（2025药事质控版本）`
- **维度**：科室、日期、抗菌药物类别。
- **粒度**：月；科室×月。
- **来源表**：需要药品医嘱/发药明细 + 药品字典（DDD 值）+ 住院人天数；当前均缺失。
- **输入字段**：**缺** 药品编码、剂量、规格、用药天数、DDD 值、给药途径；现有收费表只有金额/费别。
- **过滤/排除**：不能从收费金额反推 DDD；不能把药品收入当消耗量；外用/局部制剂是否计入待确认。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺药品医嘱/剂量/DDD 值/人天数 → NULL。
- **口径状态/待确认**：DDD 版本（WHO ATC/DDD 或本国目录）、抗菌药物范围、成人/儿童、人天数口径。**待补数据 + 待业务确认。**
- **证据/备注**：不得用“药品收入/住院人数”冒充抗菌药物使用强度。

## 6. 耗材主题（4 项）

### MOPS-CONS-01 耗材收入

- **定义**：统计期内费别属于耗材类的收费金额合计。
- **公式**：`SUM(amount) WHERE fee_type IN 耗材类 AND fee_date BETWEEN start AND end`
- **维度**：日期、科室、耗材类别、门诊/住院。
- **粒度**：日/月；科室×月。
- **来源表**：`ods_his_charge_detail` + 费别字典；当前 `his_charge.csv`。
- **输入字段**：`fee_type_code`、`fee_type_name`、`amount`、`fee_date`、`dept_code`、`visit_type`。
- **过滤/排除**：耗材类由费别字典确定；高值/低值是否分层待确认；未映射不猜。
- **当前可计算性**：**B 部分可计算**。字段存在，耗材费别字典未核。
- **NULL 原因**：耗材费别无法识别、字典缺失、金额不可解析 → NULL；真实无耗材收入 → 0。
- **口径状态/待确认**：耗材范围（卫生材料/高值耗材/低值易耗）、是否含税、按收入还是消耗。
- **证据/备注**：耗材收入不等于耗材成本。

### MOPS-CONS-02 耗占比

- **定义**：耗材收入占同期医疗收入的比例。
- **公式**：`耗材收入 / 医疗收入 × 100%`
- **维度**：科室、日期、门诊/住院。
- **粒度**：月；科室×月。
- **来源表**：`MOPS-CONS-01` / `MOPS-INC-01`，同源于收费明细 + 费别字典。
- **输入字段**：`fee_type_code`、`amount`、`fee_date`、`dept_code`、`visit_type`。
- **过滤/排除**：分子分母同期间、同范围、同字典版本；分母为 0 → NULL。
- **当前可计算性**：**B 部分可计算**（依赖耗材费别与收入口径）。
- **NULL 原因**：耗材分类缺失、分母为 0、口径未确认 → NULL。
- **口径状态/待确认**：耗材范围、是否含高值耗材、按收入还是成本。
- **证据/备注**：不宣称是官方考核口径。

### MOPS-CONS-03 住院耗材费用占比

- **定义**：住院患者耗材费用占住院总费用的比例。
- **公式**：`SUM(consumable_fee) / SUM(total_fee) × 100%`，限定出院患者与统计期。
- **维度**：科室、病种、日期。
- **粒度**：月；科室×月。
- **来源表**：`ods_his_inpatient_visit`；当前 `his_inpatient.csv`。
- **输入字段**：`visit_id`、`consumable_fee`、`total_fee`、`discharge_date`、`dept_code`、`disease_code`。
- **过滤/排除**：`consumable_fee > total_fee` 等异常隔离；分母为 0 → NULL。
- **当前可计算性**：**B 部分可计算**。字段具备；费用范围与结算状态未核。
- **NULL 原因**：费用字段缺失/异常、分母为 0、口径未确认 → NULL。
- **口径状态/待确认**：耗材范围、退费、医保结算、是否含高值耗材。
- **证据/备注**：与收费明细的耗材收入可能不一致，需对账。

### MOPS-CONS-04 百元医疗收入卫生材料消耗

- **定义**：每百元医疗收入对应的卫生材料消耗成本。
- **公式**：`卫生材料消耗成本 / 医疗收入 × 100`
- **维度**：科室、日期、院区。
- **粒度**：月/季/年。
- **来源表**：需要成本核算/材料消耗数据 + 医疗收入；当前只有收入与费别，**缺成本**。
- **输入字段**：**缺** 材料消耗成本、成本期间、科室成本归属；现有 `consumable_fee` 是收费金额，不是消耗成本。
- **过滤/排除**：不得用耗材收入代替消耗成本；成本分摊规则未确认前不计算。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺成本数据、成本期间/分摊未确认、收入口径未确认 → NULL。
- **口径状态/待确认**：成本口径（含税/不含税、进价/售价）、分摊规则、期间。**待补数据 + 待业务口径评审。**
- **证据/备注**：**不得用 `consumable_fee / revenue × 100` 冒充本指标**，那只是耗占比的变形。

## 7. 病种（DRG/DIP）主题（6 项）

> 本节全部指标涉及专业分组与权重。**业务方未确认分组器、权重版本、结算范围前，不得进入生产计算。** 病种编码/DRG 组不是本手册可以自行假定的。

### MOPS-DIS-01 出院患者病种分布（Top N）

- **定义**：统计期内出院患者按病种编码分组的例数及占比，取前 N 位。
- **公式**：`COUNT(DISTINCT visit_id) GROUP BY disease_code ORDER BY 例数 DESC, disease_code ASC LIMIT N`
- **维度**：病种 `disease_code`、科室、日期。
- **粒度**：月/季；科室×月。
- **来源表**：`ods_his_inpatient_visit`；当前 `his_inpatient.csv`。
- **输入字段**：`visit_id`、`disease_code`、`discharge_date`、`dept_code`。
- **过滤/排除**：空/未映射病种进入 `UNMAPPED` 并告警；主诊断选择规则待确认；同例数按编码升序保证稳定；不把诊断文本直接当编码。
- **当前可计算性**：**B 部分可计算**。字段存在；ICD 版本、主诊断、编码质量未核。
- **NULL 原因**：`disease_code` 整列缺失、未映射比例过高、主诊断规则未确认 → NULL。
- **口径状态/待确认**：ICD-10/ICD-9-CM-3 版本、主诊断/次要诊断、编码到病种的映射、是否按 DRG 组展示。
- **证据/备注**：病种分布不等于 DRG 分组结果。

### MOPS-DIS-02 病种次均费用

- **定义**：某病种出院患者住院总费用与出院人次之比。
- **公式**：`SUM(total_fee) / COUNT(DISTINCT visit_id)`，按 `disease_code` 分组。
- **维度**：病种、科室、日期。
- **粒度**：月/季；科室×月。
- **来源表**：`ods_his_inpatient_visit`；当前 `his_inpatient.csv`。
- **输入字段**：`visit_id`、`total_fee`、`disease_code`、`discharge_date`、`dept_code`。
- **过滤/排除**：费用缺失/异常隔离；病种未映射不归入具体病种；分母为 0 → NULL。
- **当前可计算性**：**B 部分可计算**。字段具备；病种编码与费用口径未核。
- **NULL 原因**：病种缺失/未映射、分母为 0、费用口径未确认 → NULL。
- **口径状态/待确认**：病种编码版本、费用范围、是否风险调整。
- **证据/备注**：未做风险调整的病种次均费用不能直接用于科室绩效比较。

### MOPS-DIS-03 DRG 入组率

- **定义**：本项目候选DRG口径：成功进入选定DRG分组器的病例占其合格出院病例的比例。DIP入组另定义，不默认共用。
- **公式**：`成功DRG入组病例数 / 符合所选分组器纳入条件的出院病例数 × 100%`（项目候选，非统一国家分母）
- **维度**：科室、DRG 组、日期。
- **粒度**：月/季；科室×月。
- **来源表**：需要 DRG 分组结果表 + 出院病例；当前**缺失**。
- **输入字段**：**缺** 分组状态、DRG 组编码、分组器版本、结算类型；现有只有 `disease_code`。
- **过滤/排除**：不能从 `disease_code` 自行推断入组；未入组原因需保留；分母为 0 → NULL。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺分组结果/分组器/版本、出院病例口径未确认 → NULL。
- **口径状态/待确认**：DRG分组器适用范围、分组器厂商与版本、入组规则、日间手术/转院/死亡是否纳入。**待补数据 + 待业务确认。**
- **证据/备注**：不得用“有诊断编码的病例/出院病例”冒充入组率。

### MOPS-DIS-04 CMI（病例组合指数）

- **定义**：统计期纳入DRG分析病例的总权重与分析病例总数之比；DIP不得未经版本定义直接套用本DRG公式。
- **公式**：`医院DRG总权重 / 纳入DRG分析病例总数`
- **维度**：科室、DRG 组、日期。
- **粒度**：月/季；科室×月。
- **来源表**：需要分组结果 + 权重表（含版本）；当前**缺失**。
- **输入字段**：**缺** DRG 组编码、权重、权重版本、入组病例。
- **过滤/排除**：不得用费用、住院日、诊断数量替代权重；不同权重版本不可混算；未入组病例不进入分子分母。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺权重/分组结果/版本、入组口径未确认 → NULL。
- **口径状态/待确认**：权重版本（国家/地方/医院）、DIP如另行设计须单独编码/口径、是否按风险调整。**待补数据 + 待业务确认。**
- **证据/备注**：**CMI 不是费用比，也不是平均住院日比。**

### MOPS-DIS-05 费用消耗指数

- **定义**：按选定DRG版本，将本院各病组例均费与同组参考例均费的比值，按本院该组病例数加权。
- **公式**：`SUM((本院该DRG例均费 / 参考同DRG例均费) × 本院该组病例数) / 纳入分析病例总数`。不是实际费用总量/期望费用总量，参考基准或分母缺失则NULL。
- **维度**：科室、DRG组、日期。
- **粒度**：月/季；科室×月。
- **来源表**：需要DRG分组结果、同病组区域参考例均费用及地区/版本、本院病例费用与例数；当前**缺失**。
- **输入字段**：**缺** DRG组、参考例均费用及地区/版本、本院组例均费用、本院组例数、分析病例总数。
- **过滤/排除**：不得用科室平均费用替代同DRG病组参考例均费用；不同版本标准不可混算；未入组病例不计算。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺DRG分组/同组区域参考例均费用或地区版本/分析病例数 → NULL。
- **口径状态/待确认**：同DRG组区域参考例均费用来源、地区、版本、纳入病例及异常组处理。**待补数据 + 待业务确认。**
- **证据/备注**：指数 <1 或 >1 的解释需结合病例组合，不得单独作为奖惩依据。

### MOPS-DIS-06 时间消耗指数

- **定义**：按选定DRG版本，将本院各病组平均住院日与同组参考平均住院日的比值，按本院该组病例数加权。
- **公式**：`SUM((本院该DRG平均住院日 / 参考同DRG平均住院日) × 本院该组病例数) / 纳入分析病例总数`。不是住院日总量比，缺参考基准/分母则NULL。
- **维度**：科室、DRG组、日期。
- **粒度**：月/季；科室×月。
- **来源表**：需要DRG分组结果、同病组区域参考平均住院日及地区/版本、本院组平均住院日与例数；当前**缺失**。
- **输入字段**：**缺** DRG组、参考平均住院日及地区/版本、本院组平均住院日、本院组例数、分析病例总数。
- **过滤/排除**：不得用科室平均住院日替代同DRG组参考平均住院日；未入组不计算；分母为 0 → NULL。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺DRG分组/同组参考平均住院日或地区版本/分析病例数 → NULL。
- **口径状态/待确认**：同DRG组参考平均住院日来源、地区、版本、纳入病例及异常组处理。**待补数据 + 待业务确认。**
- **证据/备注**：不得用 `INP-02 平均住院日` 冒充本指标。

## 8. 资源效率主题（5 项）

### MOPS-EFF-01 每实际占用床日住院收入

- **定义**：统计期内住院医疗收入与实际占用床日之比，反映床日产出。
- **公式**：`住院医疗收入 / 实际占用床日`
- **维度**：科室、日期、院区（待补）。
- **粒度**：月；科室×月。
- **来源表**：`ods_his_charge_detail`（住院收入）+ `ods_his_inpatient_visit`（占用床日）；当前 `his_charge.csv` + `his_inpatient.csv`。
- **输入字段**：`amount`、`visit_type`、`fee_date`、`dept_code`；`admit_date`、`discharge_date`、`stay_days`。
- **过滤/排除**：收入与床日同期间、同科室；跨期住院按日切分；分母为 0 → NULL。
- **当前可计算性**：**B 部分可计算**。字段具备；收入口径与床日切分未确认。
- **NULL 原因**：分母为 0、收入/床日口径不一致、缺日期无法切分 → NULL。
- **口径状态/待确认**：住院收入范围、床日切分、院区归属。
- **证据/备注**：课程候选工程指标，不宣称是官方效率考核口径。

### MOPS-EFF-02 医师人均门诊人次

- **定义**：统计期内门诊人次与执业医师数之比。
- **公式**：`门诊人次 / 执业医师数`
- **维度**：科室、日期。
- **粒度**：月/季；科室×月。
- **来源表**：需要门诊人次 + 人力/执业医师数据；当前**缺人力**。
- **输入字段**：`visit_id`、`visit_date`、`dept_code`；**缺** 医师数、在岗状态、统计口径。
- **过滤/排除**：不能用户籍/科室人数猜执业医师数；不能把门诊人次当医师工作量（未考虑排班与多医师）。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺医师数/在岗口径 → NULL。
- **口径状态/待确认**：执业医师/注册医师/在岗医师、全职等效（FTE）、统计期末/平均人数。**待补数据 + 待业务确认。**
- **证据/备注**：不得用收费笔数或科室人数替代。

### MOPS-EFF-03 医师人均出院人次

- **定义**：统计期内出院人次与执业医师数之比。
- **公式**：`出院人次 / 执业医师数`
- **维度**：科室、日期。
- **粒度**：月/季；科室×月。
- **来源表**：需要出院人次 + 人力数据；当前**缺人力**。
- **输入字段**：`visit_id`、`discharge_date`、`dept_code`；**缺** 医师数/在岗口径。
- **过滤/排除**：同 EFF-02；不把住院人次当出院人次。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺医师数/在岗口径 → NULL。
- **口径状态/待确认**：医师范围、FTE、期间平均人数。**待补数据 + 待业务确认。**
- **证据/备注**：不用于个人绩效排名，除非人力与病例组合调整已确认。

### MOPS-EFF-04 大型设备使用率

- **定义**：统计期内大型设备实际工作量或开机时间占额定工作量/可用时间的比例。
- **公式**：`实际工作量 / 额定工作量 × 100%` 或 `实际开机时间 / 可用时间 × 100%`
- **维度**：设备、科室、日期。
- **粒度**：月/季；设备×月。
- **来源表**：需要设备台账 + 工作量/开机记录；当前**缺失**。
- **输入字段**：**缺** 设备编号、设备分类、额定工作量、实际检查量、开机时间、可用时间。
- **过滤/排除**：不能从收费项目数量反推设备工作量；不同设备不能合并成一个“使用率”。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺设备台账/工作量/开机时间 → NULL。
- **口径状态/待确认**：“大型”定义、按工作量还是时间、额定值来源、多院区设备归属。**待补数据 + 待业务确认。**
- **证据/备注**：不宣称是官方设备绩效考核口径。

### MOPS-EFF-05 每百元固定资产医疗收入

- **定义**：每百元固定资产平均净值对应的医疗收入。
- **公式**：`医疗收入 / 固定资产平均净值 × 100`
- **维度**：科室、院区、日期。
- **粒度**：季/年。
- **来源表**：需要医疗收入 + 固定资产台账/折旧；当前**缺失**。
- **输入字段**：**缺** 固定资产原值/净值、累计折旧、期间、科室归属。
- **过滤/排除**：不能用收入代替资产；不能忽略折旧与在建工程；分母为 0 → NULL。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺固定资产数据、期间/归属未确认 → NULL。
- **口径状态/待确认**：原值还是净值、平均余额算法、院区/科室分摊。**待补数据 + 待业务确认。**
- **证据/备注**：与 `CONS-04` 不同，本指标分母是固定资产，不是卫生材料。

## 9. 患者服务主题（5 项）

### MOPS-SRV-01 门诊预约率

- **定义**：统计期内预约就诊人次占门诊人次的比例。
- **公式**：`预约就诊人次 / 门诊人次 × 100%`
- **维度**：科室、预约渠道、日期。
- **粒度**：月；科室×月。
- **来源表**：需要预约/挂号流水 + 门诊就诊；当前**缺预约标识**。
- **输入字段**：**缺** 预约标识、预约时间、预约渠道、预约状态；现有 `his_outpatient.csv` 只有 `visit_type`，不能据此判断预约。
- **过滤/排除**：不得把“专家号/普通号”当预约；不得把现场挂号算预约；取消预约/爽约是否计入待确认。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺预约数据/预约标识 → NULL。
- **口径状态/待确认**：预约渠道（APP/电话/现场/转诊）、预约成功/到诊口径、爽约处理。**待补数据 + 待业务确认。**
- **证据/备注**：不能用 `visit_type` 或就诊时间推断预约。

### MOPS-SRV-02 门诊退号率

- **定义**：统计期内退号数占挂号数的比例。
- **公式**：`退号数 / 挂号数 × 100%`
- **维度**：科室、号别、日期。
- **粒度**：月；科室×月。
- **来源表**：需要挂号/退号流水；当前**缺失**。
- **输入字段**：**缺** 挂号时间、退号时间、退号状态、号别、科室。
- **过滤/排除**：不能从收费负值推断退号；不能把作废记录当退号；退号后重新挂号是否计一次待确认。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺挂号/退号流水 → NULL。
- **口径状态/待确认**：退号定义、当日退号/跨日退号、爽约是否计入。**待补数据 + 待业务确认。**
- **证据/备注**：不宣称是官方患者服务考核口径。

### MOPS-SRV-03 患者满意度

- **定义**：有效满意度问卷中“满意/非常满意”的比例。
- **公式**：`满意问卷数 / 有效问卷数 × 100%`
- **维度**：科室、调查渠道、日期。
- **粒度**：月/季；科室×月。
- **来源表**：需要满意度调查/投诉工单；当前**缺失**。
- **输入字段**：**缺** 问卷编号、科室、时间、评分/满意度等级、有效标识。
- **过滤/排除**：不得用投诉数量反推满意度；无效问卷/重复提交需剔除；样本量过小需标注。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺满意度调查数据 → NULL。
- **口径状态/待确认**：问卷量表、满意阈值、样本抽取方式、是否按门诊/住院分。**待补数据 + 待业务确认。**
- **证据/备注**：不得编造问卷结果或“满意度 100%”。

### MOPS-SRV-04 检验报告及时率

- **定义**：统计期内按承诺时限出具报告的数量占应报告数量的比例。
- **公式**：`按时报告数 / 应报告数 × 100%`
- **维度**：科室、检验项目、日期。
- **粒度**：月；科室×月。
- **来源表**：需要 LIS 申请/采样/报告时间 + 承诺时限；当前 `lis_report.csv` 只有 `report_date`。
- **输入字段**：**缺** 申请时间、采样时间、报告时间（精确到时分）、承诺时限、项目类别。
- **过滤/排除**：不能用 `report_date` 单独判断及时；不能把报告数量当及时数量；急诊/门诊/住院时限不同需分开。
- **当前可计算性**：**C 不可计算**。
- **NULL 原因**：缺申请/报告时间与时限 → NULL。
- **口径状态/待确认**：及时率时限（TAT）定义、项目分层、节假日、外送检验。**待补数据 + 待业务确认。**
- **证据/备注**：不得用“报告日期在统计期内”冒充及时率。

### MOPS-SRV-05 病历记录关联率

- **定义**：统计期内能通过 `visit_id` 关联到 EMR 记录的就诊数占就诊总数的比例。
- **公式**：`有EMR记录的就诊数 / 就诊总数 × 100%`；按 `visit_id` 左关联，`record_id` 去重。
- **维度**：科室、就诊类型、日期。
- **粒度**：月；科室×月。
- **来源表**：`ods_emr_record` + `ods_his_outpatient_visit`/`ods_his_inpatient_visit`；当前 `emr_record.csv` + `his_outpatient.csv`/`his_inpatient.csv`。
- **输入字段**：`record_id`、`visit_id`、`dept_code`、`visit_date`；门诊/住院 `visit_id`。
- **过滤/排除**：关联键为空/重复/跨源类型不一致需隔离并告警；**本指标只表示“有记录关联”，不表示病历书写完整或质量合格**。
- **当前可计算性**：**B 部分可计算**。字段具备；`visit_id` 关联覆盖率与重复率未核。
- **NULL 原因**：关联键整列缺失、重复/冲突比例过高、门诊/住院 `visit_id` 体系不一致 → NULL。
- **口径状态/待确认**：`visit_id` 是否全局唯一、门诊与住院是否同一体系、EMR 记录是否一就诊多条、是否要求记录在就诊后一定时间内完成。
- **证据/备注**：**不得把本指标宣传为“病历书写完整率/合格率”**；后者需要完整的病历质控规则与字段。

## 官方来源复核与本轮修正（2026-11-16）

以下由Terra检索一手来源、协调者复核后补入；仍不替代医院选定制度版本与业务评审。

- **CMI区分DRG与DIP**：本项目候选DRG CMI按所选分组器下的总权重/纳入分析病例总数定义，不把同一公式直接冠以通用“DRG/DIP CMI”。国家卫健委[2022年考核指标附件](https://www.nhc.gov.cn/yzygj/c100068/202212/0f09303b966542158ac2ad656a381c08/files/1733999948319_53983.pdf)给出DRG权重口径；医保局[DRG规程](https://www.nhsa.gov.cn/art/2021/4/16/art_53_7713.html)说明病组权重汇总。DIP如采用地方CMI/分值，必须另定版本/定义，不能推论DIP绝无CMI；参照[医保局对DRG/DIP区别的解读](https://www.nhsa.gov.cn/art/2025/8/15/art_105_17575.html)。

- **平均住院日与占床日不混用**：前者围绕报告期出院患者的完整住院过程，后者围绕报告期的逐日占用；跨期住院不能把两者分子互换。参见[医院管理评价指南](https://www.nhc.gov.cn/zwgk/wtwj/201304/ac4b5d02e70b47deb9c8fce0380f225c.shtml)。
