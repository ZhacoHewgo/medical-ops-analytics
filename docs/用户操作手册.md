# 用户操作手册

## 登录与角色

在已有账号时，从 `/login` 登录，进入 `/outpatient`。管理员可管理账号和任务，分析员可查看其获准的汇总，科室账号只查看自己的科室。账号失效时重新登录。

## 查询与导出

在门诊驾驶舱选日期和科室，点击「应用筛选」。图表下方的数据表可核对日趋势和科室排行。选择「门诊报表」进入 `/reports`，按日、科室、日期加科室或月份加科室查询，使用「下钻」查看明细。「导出 Excel」或「导出 PDF」使用当前筛选和发布批次。

无记录时显示空结果。若提示数据暂不可用，先检查日期范围并重试。导出时如提示发布版本变化，请重新查询。

## 运维

管理员从「用户管理」维护角色及账户；「数据源与任务」可查看注册和任务状态。部分管理操作仅在配置允许的本地环境中开放。问数与报告接口支持认证门诊指标，其他主题以当前开通范围为准。
