# 医疗运营数据主题分析平台阶段总结

项目以课程样例数据验证采集、清洗、主题汇总、指标取数和可视化。当前支持门诊看板、认证查询及报表导出，已增加按出院日查询的住院页面。

| 目标 | 当前结果 |
|---|---|
| 数仓与数据质量 | 隔离 MySQL 已验证 ODS、DWD、维表、宽表和主题汇总；正式数据映射待确认 |
| 运营指标与主题 | 门诊人次和环比已有计算；住院均值与药品收费占比采用课程样例口径；床位及 DRG 指标待补源 |
| API、权限与展示 | 已实现账户与科室授权、门诊报表及 Excel/PDF；住院汇总可按日期和科室查询 |
| 问数与报告 | 已核对 8 个门诊回归案例；跨主题正式题集及准确率待验 |
| 性能与试运行 | 门诊总览短测 P95 为 2.32 秒；连续试运行、正式数据和课程验收待完成 |

先完成采集和门诊切片，再验证宽表及主题集市，随后接入权限、报表与住院页。技术上保留批次标识追踪发布，对缺失输入保留空值原因，按总分子和总分母计算比率。协作上由各模块负责人维护对应成果，先冻结指标口径再联调，以独立复算和重测记录核对交接结果。团队分工覆盖数据加工、服务接口、前端展示及测试集成，未统一汇总实际工时。

后续补齐床位容量和 DRG 分组权重等源数据，和课程方确认费用及住院日口径，并完成跨主题评测和连续试运行。
