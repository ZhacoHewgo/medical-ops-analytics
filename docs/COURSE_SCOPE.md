# 课程节点与本轮任务

截至2026-11-18，公开仓库仍使用已验收的节点7及节点8四维表/桥接源码基线。工作区内未通过实库验收的宽表实现没有进入公开仓库。此处是组员工作范围，不是平台完成记录。

| 节点 | 内容 | 本轮如何参与 |
| --- | --- | --- |
| 1–3 | 需求、概要设计、测试计划 | 负责人维护已形成的课程文稿；组员新增口径和验证清单，不另编业务访谈 |
| 4–7 | 环境、ODS、采集调度、清洗质检 | 复用已有代码，不让三人同时重写；用平台数据的全量结果需另做验证 |
| 8 | 四维表与就诊/收费宽表 | 负责人收口；维表语义缺口见 DATA_GAPS；未经确认不改表结构 |
| 9–10 | DWS与八主题、30指标 | A首批做平台财务日汇总与手算对照，接入宽表后再扩门诊/其他指标 |
| 11–13 | 核心API、权限、接口测试 | B首批写响应/权限矩阵与现有API回归，产品入口确认后实施 |
| 14–16 | 图表、看板、报表管理页 | C首批跑通平台门诊页并验证状态，按接口确认结果增量做组件 |
| 17–18 | NL2SQL、口径问答、报告 | 负责人暂管总体集成；B/C可后续分别承接接口和页面，当前不启模型付费接入 |
| 19 | 系统测试、对账、安全、性能 | A对账；B接口/越权；C页面。需要全链具备后再汇总，不能直接相加测试数冒称覆盖率 |
| 20 | 部署、试运行、手册与总结 | 负责人最终集成，三人补各模块使用步骤；本轮不提交平台终稿或成果代码包 |

建议检查点是领取任务后首日交一次能复现的草稿，不是约定课程截止日。准确截止时间和各人可投入时间仍需在组内确认。遇到公共文件冲突先停下交给负责人，不同时修改同一文件。
