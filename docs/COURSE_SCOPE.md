# 课程节点范围

| 节点 | 内容 | 验证范围 |
| --- | --- | --- |
| 1–3 | 需求、概要设计、测试计划 | 需求、概要设计、测试计划、指标口径和验证清单。 |
| 4–7 | 环境、ODS、采集调度、清洗质检 | 复用现有采集和清洗链路，单独验证课程数据的全量结果。 |
| 8 | 四维表与就诊/收费宽表 | 核对四张公共维表及两张宽表。维表语义缺口见 [数据缺口](DATA_GAPS.md)。 |
| 9–10 | DWS与八主题、30指标 | 按日和科室独立核对财务汇总，再验证门诊和其他主题的指标。 |
| 11–13 | 核心API、权限、接口测试 | 验证响应结构、鉴权、科室范围和 API 回归。 |
| 14–16 | 图表、看板、报表管理页 | 验证图表、页面状态、筛选及报表导出。 |
| 17–18 | NL2SQL、口径问答、报告 | 用可查询的指标验证问数、口径问答和报告。 |
| 19 | 系统测试、对账、安全、性能 | 分别记录数据对账、接口越权和页面验证结果。 |
| 20 | 部署、试运行、手册与总结 | 验证部署和试运行，整理使用手册与验收记录。 |
