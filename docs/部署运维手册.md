# 部署运维手册

四服务隔离环境由 MySQL、FastAPI、Vue 和 Nginx 组成。仅 Nginx 绑定本地回环地址。按 [隔离部署步骤](../deploy/README.md) 准备合成聚合数据和临时密码文件，再启动服务。

在准备环境变量和本次项目名后，用以下命令检查与停机：

```sh
docker compose -f deploy/docker-compose.yml -p "$mops_project" ps
docker compose -f deploy/docker-compose.yml -p "$mops_project" logs --tail=100 backend nginx
docker compose -f deploy/docker-compose.yml -p "$mops_project" down
```

用网关 `/health` 检查 API，再查看门诊总览与健康状态。测试部署的 MySQL 使用临时存储，适合用受控合成数据重建。持久库备份与恢复应在隔离库校验后执行。认证环境的初始化、回刷和定时验证见[试运行步骤](../deploy/auth-pilot.md)；凭据从本地私有配置注入。
