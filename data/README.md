# 平台数据准备与共享范围

本轮仅使用课程平台提供的数据。不下载第三方公开数据，不提交生成器生成的数据文件。课程目录称为模拟数据，但其生成来源未独立验证。

## 文件清单

| 文件 | 用途 | GitHub 当前状态 |
| --- | --- | --- |
| `files/finance_excel.csv` | 日期、科室收入、药品收入、耗材收入汇总 | 已收录平台原文件，910 行，无患者列 |
| `mock_his/his_outpatient.csv` | 门诊人次、日期趋势和科室排行 | 未公开；组员从课程平台下载 |
| `mock_his/his_inpatient.csv` | 入出院、住院日和费用候选统计 | 未公开；组员从课程平台下载 |
| `mock_his/his_charge.csv` | 逐笔收费和费别统计 | 未公开；组员从课程平台下载 |
| `mock_his/emr_record.csv` | 病历与病种编码关联 | 未公开；组员从课程平台下载 |
| `mock_his/lis_report.csv` | 检验项目和报告记录 | 未公开；组员从课程平台下载 |

五份明细都含患者标识或可关联的医疗记录；门诊和住院表还含姓名、证件号、手机号。当前未取得全部虚构及允许公开再分发的明确依据，不将这些内容放进公开 Git 历史。财务文件只有记录编号、统计日期、科室及三类金额，按用户本轮共享要求原样收录；它不是患者收费明细。

## 组员操作

1. 登录课程平台，进入本项目的“数据材料”，下载“医疗运营数据主题分析平台数据集.zip”。若无访问权限，找负责人通过课程允许的方式交接，不从陌生网站找同名文件。
2. 在本地解压。找到上述六份 CSV，按目录放入本仓库。若解压后多了一层目录，复制文件到下方位置，不修改 CSV 内容。
3. 财务 CSV 仓库已有；下载版本不同时先对照文件指纹，不直接覆盖已跟踪文件。五份明细被 `.gitignore` 排除。
4. 门诊看板只需要门诊 CSV，其余任务按需准备。不要为了启动页面连接云数据库或启动每日定时任务。
5. 不把患者记录复制给在线 AI。提问只带源码、字段名、公式和脱敏的错误类型，不贴原始行或包含原行的堆栈。

```text
medical-ops-analytics/
  data/
    files/finance_excel.csv
    mock_his/
      his_outpatient.csv
      his_inpatient.csv
      his_charge.csv
      emr_record.csv
      lis_report.csv
```

[原文件字段与 SHA256 清单](../docs/platform-data-inventory.json)只含文件信息和表头，没有患者记录。不同版本先由负责人确认，不能用改过的数据去对照旧版验收数字。

## 财务文件口径

现有字段是 `record_id, stat_date, dept_code, revenue, drug_revenue, consumable_revenue`。先按日期和科室聚合；有重复或冲突时登记，保留原文件，不自行删除。收入、药品收入和耗材收入的实际统计关系还需课程口径确认。不得将财务收入与逐笔收费直接相加，也不得把差异强行调为零。
